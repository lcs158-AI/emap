## 一、升级目标

在现有「姿态控制 + 手机双按键 + 物理弹道」基础上，把玩法从单一练靶升级为**四种战场的限时歼灭战**：

1. 四个模式（公路 / 野战 / 海战 / 空战），地图地形、氛围、敌方装备编成各不相同。
2. 玩家战机、敌方坦克 / 装甲运兵车 / 军舰 / 敌机等改为**程序化写实低多边形模型**，地形起伏真实、可遮挡、可碰撞。
3. 敌方具备开火能力：炮弹（抛物线）与导弹，可击伤 / 击毁玩家。
4. 玩家武器分为**机炮（无限弹药）与导弹（每局 10 发）**，装甲目标需多次机炮命中才能摧毁。
5. 新的计分与结算：按目标体型计分、未命中扣分、限时清空或战机被毁即结束。

不包含（本阶段）：音效、多人联机、账号系统、排行榜、商城。

## 二、玩法总览

| 模式 | 地图核心 | 敌方构成 | 限时 | 结束条件 |
|---|---|---|---|---|
| 公路 | 平原 + 低缓丘陵 + 蜿蜒公路 | 装甲车队沿公路推进、路边炮塔、终点地堡 | 120s | 清空全部敌方目标（胜利）/ 时间到仍有残余（失败）/ 战机被毁（失败） |
| 野战 | 起伏丘陵、山脊、沟壑、树林与村落 | 山脊/山谷中的坦克群、装甲车、炮塔、指挥堡 | 150s | 同上 |
| 海战 | 动态海面 + 岛屿 + 舰船尾流 | 驱逐舰、护卫舰、快艇编队、岛礁炮台 | 150s | 同上 |
| 空战 | 高空云层 + 远海/大地 | 敌方战机编队、无人机、预警机、地面雷达站 | 120s | 同上 |

统一规则：
- 每局开局重置：战机护甲 3 格、导弹 10 发、分数 0、倒计时按模式设定。
- 战机被**敌方导弹**命中 → 立即击毁（直接失败）。
- 战机被**敌方炮弹**命中 → 护甲 −1，累计 3 发 → 击毁（失败）。
- 清空全部敌方目标 → 立即胜利（剩余时间转为结算奖励可选项，默认不加分）。
- 目标总数即「清空」判定口径，包含地面/海面固定目标与移动单位。

## 三、操作与武器

### 3.1 控制映射（沿用手机双按键，含义改为双武器）

| 端 | 操作 | 功能 |
|---|---|---|
| 电脑 | 摄像头前左右移动 | 姿态控制战机平移（保留平滑/置信度过滤/边界锁定） |
| 电脑 | A / D 或 ← / → | 键盘备用平移 |
| 电脑 | J / 空格（按住）（V2.7.0） | 机炮连射 |
| 电脑 | K（单击）（V2.7.0） | 发射导弹（双发） |
| 电脑 | L（单击）（V2.7.0） | 释放干扰弹（双发） |
| 手机 | 横屏左侧大按钮（按住） | 机炮连射 |
| 手机 | 横屏右侧大按钮（单击） | 发射导弹 |
| 手机 | 横屏顶部状态条 | 显示「已连接电脑」、导弹余量、护甲、剩余时间、得分（主机 2Hz 同步） |

> 原来的「左/右发射口」视觉保留：机炮由左右机炮口交替射出，导弹由机腹中线挂架发射。

#### 3.1.1 手机横屏控制布局

手机端固定为**横屏操作**，左右手拇指自然落在两侧按钮上：

- **方向提示**：竖屏打开时显示全屏提示「请横屏使用」，旋转后自动进入控制界面；不强制调用浏览器锁屏 API。
- **左侧机炮按钮**：占左半屏主要区域，按住连发，按钮内显示「机炮 · 无限」。
- **右侧导弹按钮**：占右半屏主要区域，单击发射，按钮内显示导弹余量图标与剩余发数（如「导弹 7/10」）。
- **顶部状态条**：从左到右为「已连接电脑」状态、护甲 3 格、导弹余量、倒计时、得分。
- **冷却表现**：机炮按钮显示微弱的射速节流提示；导弹按钮显示 1.5s 环形冷却遮罩，弹药耗尽后置灰并显示「弹药耗尽」。
- **防误触**：横屏安全区适配（刘海屏 `env(safe-area-inset-*)` / `100dvh`），按钮间距 ≥ 16px，按下有触感反馈（震动）。
- 横屏下不出现滚动条，页面禁止缩放与双击放大。

### 3.2 机炮

| 参数 | 值 | 可调 |
|---|---|---|
| 弹药 | 无限 | — |
| 射速 | 8 发/秒（按住连发） | 是 |
| 弹速 | 150 | 是 |
| 散布 | ±1.0° | 是 |
| 有效射程 | 180 | 是 |
| 枪口 | 左右机炮口交替 | — |
| 伤害 | 小型目标 1 发、中型 2 发、大型 3 发击毁 | 是 |
| 每次命中得分 | +10 | 是 |
| 未命中惩罚 | −3 / 发 | 是 |
| 拦截 | 可击落飞行中的敌方导弹（命中 +30） | 是（可选） |

### 3.3 导弹

| 参数 | 值 | 可调 |
|---|---|---|
| 每局数量 | 10 发 | 是 |
| 冷却 | 1.5s | 是 |
| 弹速 | 90 | 是 |
| 制导 | 弱制导：锁定准星前方 ±25° 内最近目标，转向 ≤60°/s；丢失目标后按弹道飞行 | 是（可改为纯抛物线） |
| 命中效果 | 任意敌方目标直接击毁 | — |
| 命中得分 | 按目标体型 +100 / +200 / +300 | 是 |
| 落空惩罚 | −60 / 发 | 是 |

### 3.4 敌方武器

| 单位 | 武器 | 对玩家效果 | 备注 |
|---|---|---|---|
| 坦克 / 装甲车 / 炮塔 | 炮弹（抛物线，带提前量） | 护甲 −1 | 3 发击毁战机 |
| 指挥堡 / 雷达站 | 火箭弹 / 近程导弹 | 直接击毁 | 弹速较慢、有来袭预警 |
| 军舰 | 主炮炮弹 + 舰空导弹 | 炮弹 −1 护甲；导弹直接击毁 | 舰炮齐射 |
| 敌方战机 | 空对空导弹 | 直接击毁 | 追踪玩家，可被机炮拦截 |

- 敌方开火间隔：炮弹 3–5s/单位，导弹 8–12s/单位（按模式难度微调）。
- 来袭预警：屏幕边缘红色箭头 + 距离读数 + 屏幕轻微抖动，给玩家 0.8–1.5s 反应时间。
- 敌方单位有各自射程，玩家需进入射程才会被攻击。

## 四、伤害、计分与结算

### 4.1 目标体型与装甲

| 体型 | 代表目标 | 机炮击毁所需命中 | 导弹 | 击毁得分 |
|---|---|---|---|---|
| 小型 | 公路炮塔、快艇、无人机 | 1 | 1 | +100 |
| 中型 | 装甲运兵车、护卫舰、岛礁炮台、敌机、雷达站 | 2 | 1 | +200 |
| 大型 | 主战坦克、驱逐舰、预警机、指挥地堡 | 3 | 1 | +300 |

### 4.2 计分规则

| 事件 | 分数 |
|---|---|
| 机炮命中但未击毁 | +10 |
| 击毁小型 / 中型 / 大型 | +100 / +200 / +300 |
| 机炮落空（弹丸未触碰任何目标即消失） | −3 / 发 |
| 导弹落空 | −60 / 发 |
| 机炮拦截敌方导弹 | +30（可选功能） |
| 分数下限 | 0（不出现负分） |

说明：击毁得分按「体型」，不叠加目标原有分值；地面/海面固定目标与移动单位同规则。

### 4.3 结束与结算

- 胜利：敌方目标全部击毁（不论剩余时间）。
- 失败：倒计时归零仍有目标；或战机被击毁（立即结束）。
- 结算面板：胜负、得分、击毁数/目标总数、机炮命中率、导弹剩余、用时。
- 结算后可「重玩本模式」或「返回模式选择」。

## 五、模式详细设计

### 5.1 公路模式（120s）

- **地形**：平原为主，叠加 2–3 层低频噪声形成低缓丘陵；一条 S 形公路纵贯地图（沿线地形压平 ±8 单位），带中央虚线、护栏、路灯。
- **场景**：田野色块、成排树木（实例化）、远处高压线塔、路边指示牌；晴天暖光。
- **敌方编成（13）**：装甲运兵车 ×6（中型，沿公路推进）、主战坦克 ×3（大型，车队护卫）、路边炮塔 ×3（小型）、终点指挥地堡 ×1（大型）。
- **玩法要点**：低空掠地飞行，目标沿公路呈线状分布，适合机炮扫射车队；地堡发射火箭弹，需优先用导弹清除。

### 5.2 野战模式（150s）

- **地形**：起伏最明显——高差 40–70 单位的丘陵与山脊、沟壑、缓坡；地表按坡度混合草/土/岩石颜色。
- **场景**：树林、灌木、村落残墙、弹坑、掩体沙袋、铁丝网；多云漫射光。
- **敌方编成（16）**：主战坦克 ×5（大型）、装甲车 ×5（中型）、固定炮塔 ×4（小型）、指挥堡 ×2（大型）。
- **玩法要点**：地形遮挡视线与弹道，需要拉高观察再俯冲攻击；山谷中的目标易被山脊挡住，需绕后。

### 5.3 海战模式（150s）

- **地形**：动态海面（3 组 Gerstner 波叠加，顶点位移 + 法线扰动），散布岛屿（沙滩→草地→岩石）；玩家在离海面 8–15 单位掠海飞行。
- **场景**：舰船尾流（半透明拖尾面片）、浪花、远处海岛、海雾。
- **敌方编成（11）**：驱逐舰 ×2（大型）、护卫舰 ×3（中型）、快艇 ×4（小型）、岛礁炮台 ×2（中型）。
- **玩法要点**：舰船会随浪起伏并巡航；主炮齐射覆盖范围大，需保持机动；舰空导弹有预警，可用机炮拦截。

### 5.4 空战模式（120s）

- **地形**：高空战场，三层程序化云（billboard 云团 + 体积感雾）、下方远海/大地；无复杂地面碰撞。
- **场景**：云层、太阳光晕、敌机尾焰、导弹尾迹。
- **敌方编成（12）**：敌方战机 ×5（中型）、无人机 ×4（小型）、预警机 ×1（大型）、地面雷达站 ×2（中型，位于下方地面）。
- **玩法要点**：敌机做盘旋/俯冲机动并发射追踪导弹；玩家用弱制导导弹追击，或近身机炮点射；地面雷达站需下降高度攻击。

## 六、视觉与拟真方案

### 6.1 地形与场景

- 每个模式使用独立随机种子生成**高度图**（4 层 fbm 噪声），网格 144×144 段，顶点色按坡度/高度混合（草地/泥土/岩石/沙滩），远处用雾衰减。
- 统一提供 `getGroundHeight(x, z)` 采样函数，供：目标摆放贴合地面、弹丸落点判定、相机防穿地、玩家高度限制。
- 公路：沿样条压平并铺设路带网格；野战：增加沟壑与山脊；海战：海面网格顶点动画 + 岛屿高度图；空战：云层精灵 + 远景地形。
- 程序化 canvas 纹理（迷彩、金属噪点、海面法线），不引入外部贴图文件，保证局域网离线可用。

### 6.2 模型（全部程序化建模，写实低多边形）

| 对象 | 主要部件 |
|---|---|
| 玩家战机 | 机身、座舱盖、主翼、垂尾、进气道、双发动机喷口（加力光效）、机腹挂架、左右机炮口 |
| 主战坦克 | 车体、可旋转炮塔、炮管（开火后座动画）、履带（滚动贴图偏移）、负重轮、观察窗、天线、迷彩色块 |
| 装甲运兵车 | 车身、8 轮/履带、顶部机枪塔、车窗、防弹板 |
| 驱逐舰 / 护卫舰 | 船体（截面挤出）、甲板、舰桥、烟囱、雷达桅杆、主炮、近防炮、尾流 |
| 快艇 | 船体、驾驶台、舷外机、尾流 |
| 敌方战机 / 无人机 | 机身、三角翼/旋翼、座舱、尾焰 |
| 固定目标 | 炮塔、地堡、雷达站（天线旋转） |

- 材质：PBR（MeshStandardMaterial）+ 程序化贴图；用 PMREM 生成的简单环境贴图提升金属/舰体质感。
- 光照：方向光（带阴影，2048 阴影图，仅玩家与近距目标投影）+ 半球环境光；不同模式不同色调（公路暖、野战冷绿、海战蓝青、空战高亮）。
- 受损表现：命中火花、冒烟（受伤未毁）、击毁爆炸 + 少量碎片 + 残骸坠落；玩家受击红色暗角 + 相机抖动。

### 6.3 性能预算

- 目标：1080p ≥ 50fps（集显）；三角面 ≤ 15 万，Draw Call ≤ 250。
- 树木/草丛/岩石使用实例化；远处目标不投影；雾裁剪；纹理 ≤ 512²。
- 物理固定步长 1/120s；敌方 AI 10Hz；姿态识别 15Hz；网络状态同步 2Hz。

## 七、技术架构调整

### 7.1 状态机

`MENU（模式选择）→ COUNTDOWN（3-2-1）→ PLAYING → RESULT（胜利/失败）→ MENU / 重玩`

### 7.2 模块拆分（纯静态 ES Module，无打包工具）

| 文件 | 职责 |
|---|---|
| `index.html` | 入口、HUD 骨架、模式选择/结算界面 |
| `styles.css` | HUD 与界面样式（从 index.html 中抽出） |
| `src/config.js` | 全局参数、四模式配置表、计分表 |
| `src/utils.js` | 数学、随机数、噪声、对象池 |
| `src/terrain.js` | 高度图生成、地面/海面/云、`getGroundHeight` |
| `src/models.js` | 程序化模型工厂（战机/坦克/装甲车/舰船/目标） |
| `src/player.js` | 玩家战机、护甲、姿态/键盘控制 |
| `src/weapons.js` | 机炮/导弹/敌方弹药、制导、碰撞、伤害结算 |
| `src/enemy.js` | 敌方单位生成、巡逻、瞄准、开火 AI |
| `src/game.js` | 模式切换、计时、计分、胜负判定、主循环 |
| `src/hud.js` | HUD、预警、结算面板 |
| `src/pose.js` | MediaPipe Pose（由现有代码迁移） |
| `src/net.js` | Socket.IO 客户端（主机端） |
| `controller.html` | 手机横屏双武器控制器（左右拇指按钮 + 余量/护甲/时间显示） |
| `server.js` | 静态托管 + 信令转发（武器指令、状态同步） |

### 7.3 通信协议（V2）

```
controller → server → host:
  weapon { type: 'cannon', action: 'down' | 'up' }
  weapon { type: 'missile' }

host → server → controllers:
  state { mode, time, score, ammo, armor, remaining, result }

公共:
  join { role: 'host' | 'controller' }
  presence { host, controllers }
```

- 游戏逻辑全部在电脑端（主机权威），服务端只做转发，改动小。
- 手机端按钮冷却与弹药显示由主机 `state` 驱动，避免双端状态不一致。

### 7.4 碰撞与物理

- 玩家/敌机：球形包围体；舰船/建筑：近似 OBB（轴对齐包围盒 + 朝向）。
- 敌方炮弹带重力与提前量；敌方导弹弱制导追踪玩家；玩家导弹弱制导追踪最近锁定目标。
- 弹丸生命周期：命中、落地/入水、超时（3.5s）、超界即销毁；未命中的机炮弹与导弹按规则扣分并计数。
- 机炮对目标采用「连续步进 + 线段扫掠」检测，避免高速穿透漏判。

## 八、HUD 与界面

- 左上：模式名、倒计时、剩余敌数、得分。
- 左上第二行：护甲 3 格（受损变红）、导弹余量 10 格。
- 左下：机炮/导弹状态（射速冷却、导弹冷却）。
- 中屏：准星、锁定框（导弹锁定时显示）。
- 屏幕边缘：来袭导弹/炮弹红色箭头预警。
- 右上：摄像头/姿态/网络状态灯 + 二维码（保留）。
- 模式选择页：4 张模式卡片（缩略图 + 敌情概要 + 时长）。
- 结算页：胜负、得分、击毁数、命中率、导弹剩余、用时；按钮「重玩」「换模式」。

### 8.1 手机端（横屏）

- 进入即检测方向：竖屏显示「请横屏使用」遮罩，旋转后自动消失。
- 布局：左半屏=机炮按钮，右半屏=导弹按钮，顶部为状态条（连接状态 / 护甲 / 导弹余量 / 倒计时 / 得分）。

## 十一、验收标准

1. 四个模式均有独立地形与敌方编成，切换后场景、目标类型和数量明显不同。
2. 地形有明显起伏/海浪/云层，目标贴合地形，弹丸落点按地面高度判定。
3. 玩家战机、坦克、装甲车、军舰、敌机造型可辨识，非单一方块。
4. 敌方会主动发射炮弹与导弹，玩家会收到来袭预警。
5. 玩家机炮对大型目标需 3 发命中击毁，中型 2 发，小型 1 发；导弹 1 发击毁任意目标。
6. 玩家导弹每局 10 发，用尽后无法发射；机炮无限。
7. 玩家被敌方导弹命中立即失败；累计 3 发炮弹命中失败。
8. 计分：击毁按体型 100/200/300，机炮命中 +10，机炮落空 −3，导弹落空 −60，分数不低于 0。
9. 清空目标立即胜利；时间耗尽未清空失败；战败/胜利均显示结算并支持重开。
10. 手机控制器横屏操作，左右两侧分别为机炮/导弹按钮，显示弹药、护甲与倒计时，局域网联动正常。

## 十二、已确认设计决策（2026-11-07）

1. **手机横屏操作**：控制器固定横屏；左半屏=机炮（按住连发），右半屏=导弹（单击），顶部状态条显示护甲/弹药/倒计时/得分。（评审时确认调整）
2. **导弹制导**：弱制导——锁定准星前方 ±25° 内最近目标，转向 ≤60°/s，丢失目标后按弹道飞行。（已确认）
3. **战机被毁**：立即失败并结束本局，进入结算。（已确认）
4. **机炮拦截敌方导弹**：开启，拦截成功 +30 分。（已确认）
5. **计分默认值**：击毁 100/200/300，机炮命中 +10，机炮落空 −3/发，导弹落空 −60/发，分数下限 0。（已确认，可在 `src/config.js` 调整）
6. **控制映射（V2.7.0 更新）**：手机横屏左机炮、中干扰弹、右导弹；键盘左手 A/D/W/S/Z/X 飞行，右手 J/空格=机炮（按住）、K=双发导弹、L=双发干扰弹，旧键 Q/E/F 停用；原左右发射口仅作视觉保留。（已确认）

## 十四、风险与说明

- **拟真度与性能**：不引入外部 3D 模型/贴图，采用程序化低多边形写实风格；若后续需要更高拟真度，可增量引入 GLB 模型与 PBR 贴图。
- **摄像头依赖**：V2.0 的 3D 引擎与姿态库均走 CDN；V2.7.0 公网版优先使用本地自托管资源，摄像头、视频播放与模型初始化均有超时和节点重试，失败时明确降级为键盘模式。
- **手机浏览器**：控制器页为纯 HTML/JS，微信内置浏览器已可打开；若网络策略变化，备用手动输入地址。
- **平衡性**：敌方开火频率、护甲、导弹数量集中在 `config.js`，便于后续调参。
