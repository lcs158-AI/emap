# 跬步 · 小刘智能空间矩阵

用于开展在线空间信息技术研发和展示的 Web 项目（纯前端静态站点，可部署到任意静态托管平台）。

线上站点：`lzywhy.com`。

## 项目定位

一个集成多种地图技术的在线空间数据平台，由若干相对独立的「板块」构成。板块间尽量自包含（自带依赖库与数据），仅共享基础工具脚本，便于独立开发、维护与部署。

## 主要功能

- **多源底图**：天地图、ESRI 影像（根据是否位于 `lzywhy.com` 域名自动切换）
- **地理数据加载**：支持 `.geojson` / `.json` / `.kml` / `.kmz` / `.gml` 上传
- **图层管理**：动态图层增删、显隐、编辑（`js/layer_editor.js` + `js/feature_form.js`）
- **测量与潮汐**：地图测量、实时潮汐曲线
- **手机遥控**：电脑端打开 `AIsea.html` → 左侧缩放按钮下方的 📱 →「手机扫码遥控」，面板根据电脑端登录状态自动提供一种模式
  - **未登录 · 简易遥控**：手机扫码进入 `mapctl/`，支持摇杆平移、按住缩放、手机定位、底图切换
  - **已登录 · 地图镜像**：手机扫码打开同一张地图（`AIsea.html?mirror=1`），需在手机上用同一账号登录；登录后两端加载同一份数据，同步拖动/双指缩放、测长测面、底图、地名搜索、手机定位与 POI 标记；支持清除测量，以及电脑配置图层和本地图层的显隐、缩放、移除与刷新
  - **镜像页「不登录，仅遥控」**：登录页底部可选择不登录直接遥控；此模式下手机端不加载账号数据，因此不显示「图层」入口、不同步弹窗，仅保留拖动/缩放、测量、底图、地名搜索、定位与激光笔
  - 测量完成后自动替换上一次结果；手机点「清除」或电脑点「清除测量」可清除当前电脑上的测量线/面和结果文本
  - **激光笔**：镜像页底部开启「🔦 激光」，可按「点 / 划线 / 划圈」在手机和电脑地图上同步投射激光点、激光轨迹或激光圈；落点采用白芯红晕的高亮脉冲光点，停止后自动淡出，「清除」同时清空两端
  - **弹窗与图层同步**：任一端点击要素，两端弹出同一信息；任一端关闭弹窗（含点弹窗「×」）另一端同步关闭；电脑端图层显隐同步到手机本地同名图层
  - **安全配对码**：面板打开即生成 6 位配对码（120 秒有效，可点「刷新」重新生成），并嵌入二维码；手机扫码后自动配对，若二维码已过期或手动打开链接，则需在手机端输入面板显示的配对码；未配对前任何手机都无法下发指令，电脑主机下线后配对码立即失效
  - **本地操作优先**：在电脑端拖动地图或滚轮缩放的 1.2–1.8 秒内，手机传来的视图、测量、定位、弹窗等指令会被忽略，避免与本地操作抢地图
  - **断开手机遥控**：面板底部「断开手机（N）」可一键断开所有手机并立即更换配对码，旧链接与旧配对码随即失效，手机需用新码重新配对
  - 两端需使用同一账号；电脑端本地导入的文件（浏览器本地数据）不会自动传到手机，需要一致时请先上传到账号数据
  - 手机直接打开 `AIsea.html` 时（非镜像模式）遥控入口自动隐藏，直接用触摸操作地图
- **三维用海（Three.js 版）**：直接访问 `sea3d/index.html`（当前独立运行，暂未接入跬步地图工具栏，待功能完善后再加入口）
  - 打开即加载 `data/sea_use/demo.geojson`（示例数据，非真实用海项目）；也可「导入数据」选择本地 `.geojson` / `.json` / `.kml`
  - 以数据范围中心做局部米制投影（x 东、z 南、y 高程），小范围近似，适合几百米至数公里的用海单元
  - 棱体按底高/顶高拉伸成棱柱并描边，管线按每个节点的第三维高程逐段成管，节点以球体显示
  - 支持 1×/2×/5×/10× 高程夸张（标签与信息始终显示真实高程）、俯视/斜视/侧视/水下视角、图层开关与点击拾取
  - **模拟地形**：参照小刘游戏海战场景，使用浅蓝天空、雾与暖色阳光；西北侧为陆地和海岸线，东南侧开海；海洋拆为海床（泥沙纹理 + 顶点着色地形）、水体（半透明水层）与海面（波纹法线贴图 + 动态波浪）三层，陆地/海床/水体/海面可分别显隐
  - 海床对水下深度做吸收着色（越深越暗、越偏深蓝），让水体呈现有色体积而非空气；海床下增设底土实体侧壁与底盖，形成海床的下边界；海岸线泡沫带强化陆地 / 海面边界
  - 当前地形与纹理为噪声高度场模拟效果，后续接入实测「海域面 / 陆地面 / 水深点」时只需替换 `sea3d/js/sea3d_env.js` 中的高度场与纹理数据来源
  - 示例数据按用海类型的真实竖向占位设置：养殖区从海床到海面略上、人工鱼礁贴海床、管线与桥梁下部位于海床以下、疏浚区从海面到海床以下；海床半透明显示，默认即可看到埋设管线与下部结构
  - 两版三维用海共用 `js/sea_use_data.js` 解析，字段约定见本节末尾

- **游戏**：键盘 / 手机 / 体感 / 语音多种操控方式
- **小刘听写**：访问 `dictation/index.html`，先用豆包、微信或 QQ 等 AI 工具拍照提取词语，复制文字后点「粘贴中文」或「粘贴英文」导入；页面分别只保留汉字或英文单词，并以空格分隔，也支持直接在输入框粘贴或手动输入。校对后可设置每词朗读次数和词间停顿。浏览器支持 Web Speech API 且存在可用语音时使用本机朗读，词语不上传；本机语音不可用或朗读报错时，自动改用后端 Edge TTS（`/api/tts/speak`）合成音频，此时词语会发送到后端，需要联网。后端地址可用 `?server=` 指定，默认 `https://lzy-fastapi.onrender.com`

### 三维用海数据字段

| 数据字段 | 优先级（GeoJSON / KML 通用） | 说明 |
|------|------|------|
| 底高 | `bottom`、`bottomHeight`、`底高` | 高程（米），负值水下 |
| 顶高 | `top`、`topHeight`、`顶高` | 小于底高时自动交换并告警 |
| 高程 | `elevation`、`height`、`高程` | 缺顶高时作为顶高；管线节点缺第三维时作为节点高程 |
| 名称 | `name`、`名称` | 缺省为「棱体 N / 管线 N」 |
| 颜色 | `color`、`fill`、`stroke`、`颜色` | 支持 `#RRGGBB`、`rgb()`、CSS 颜色名与 KML 8 位色 |
| 线宽 | `width`、`线宽` | 管线直径（米），缺省 4 |

> 说明：GeoJSON 的 `Polygon`/`MultiPolygon` 视为棱体，`LineString`/`MultiLineString` 视为管线；KML 通过 `ExtendedData` 读取上述中英文字段，不依赖 Cesium 的高度推断，保证两端结果一致。多边形空洞会忽略，无法解析的要素会跳过并在页面「数据告警」中列出。

## 本地运行

项目为纯静态站点，任选一种方式在仓库根目录启动 HTTP 服务：

```bash
# Python
python -m http.server 8080

# Node（如需）
npx serve
```

然后浏览器访问 `http://localhost:8080/index.html`。

> 注意：Cesium（跬步地球）、天地图等部分功能依赖外网服务；直接在浏览器用 `file://` 打开可能因跨域限制导致部分资源/数据加载失败，建议用本地 HTTP 服务访问。

## 部署

- 直接部署到静态托管平台（如 GitHub Pages / Render / 数据本地存储），`CNAME` 配置了 `lzywhy.com` 域名。
- 全站无构建步骤，上传仓库内容即可。
